Assumptions:
  • Treated credibility-weighted polarity as the headline number on each tile (24px) and raw net polarity as the secondary read — credibility is the whole point of the project.
  • Assumed Wilson-95 CIs are always shown alongside any rate metric, even when N is small; the bracket itself is the warning, not just the banner.
  • Assumed the user reads top-to-bottom, left-to-right: header, then signal strip, then chart with markers, then evidence. Right rail is reference material.
Decisions & reasoning:
  • Chose a 4-5-3 column split (not 3-6-3) — the chart wants horizontal room, and the 6 signal tiles work better as a 3×2 grid spanning the left rail width than stacked.
  • Evidence quotes default open on the first 2 rows, collapsible on the rest — first impression should show the project's raison d'être (verbatim quotes), but a 5-row table all-open would dominate the fold.
  • Polarity micro-bar uses a hollow square marker, not a filled dot — keeps data-ink ratio high and matches the "no fills" rule on badges. The center tick is the zero reference.
Open tradeoffs / to decide:
  • Sparklines are currently cyan (info color). Considered coloring them by sign of last value (green/red), but mixed signs in the same column would make the table visually noisy. Flag for review.
  • The "Historical only" header slot is reserved but not rendered (most-recent mention is 5 days old). Slot is the empty space right of the price block — consider whether it should always render as a placeholder for layout stability.
  • Low-N banner shown as inactive example in the methodology footer per spec, but real placement would be above the signal strip — should it also reserve vertical space when inactive? Currently it does not, to avoid wasted real estate.
Reference inspiration:
  • Tile typography references Bloomberg's TKR <GO> / RV <GO> functions; chart axis style + sparkline density references Tufte's small multiples and Cleveland's dot plots; hairline grid + hollow badges reference FactSet workstation chrome.
