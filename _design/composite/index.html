// design-notes — composite production candidate (strip at port)

What this is: the merge of Terminal A (dark Bloomberg/Tufte chassis) + Brief B (editorial pull-quote moment) + Tape C (bracketed metadata grammar & epistemic-honesty footer). Intended as the visual spec for production port to apps/web/src/app/tickers/[ticker]/page.tsx.

// 3 transplant decisions & reasoning

  • Newsreader serif-italic confined to expanded claim drawer only. The page reads like a terminal during scan; only when a reviewer stops to read the verbatim creator voice does it flip register. Mixing serif elsewhere would dilute the chassis.
  • Bracketed metadata grammar (Tape) lifted everywhere; ASCII box-drawing rules left behind. The [N=4][W=7d] idiom is signal-dense and Tufte-compatible; ASCII boxes would fight the hairline 1px-rule chassis.
  • N-warning banner kept in styled-inactive demo state. Per locked constraint — sample-size warnings are a visible product feature even when suppressed; the production code needs a documented treatment for the live state.

// 3 things still open before port

  • Responsive collapse strategy <1280px (3-col -> 2-col -> stacked); right-rail creator coverage may want to demote to a tab on mobile.
  • Drawer open/close transition timing — currently instant via <details>; consider 120ms ease-out height + 80ms cyan-rule fade-in for the editorial moment.
  • Sparkline interactivity — static SVG here; production should hover-link to the underlying claim rows (filter coverage panel by selected creator).

// definitions
claims_all — every extracted Claim on this ticker, summed with creator-credibility weights. Captures the broadest signal including opinions and conditional statements.
claims_factual — subset of Claims marked class=factual (verifiable assertions: levels, catalysts, data points). Excludes opinions and conditionals. Lower N, higher signal-to-noise.
creator_consensus — per-creator polarity averaged then weighted. Limits one loud creator's effect — each creator counts once per window regardless of mention count.
credibility_weighted_polarity — Σ(polarity · cred_weight) / Σ(cred_weight); cred_weight derives from each creator's hit-rate Wilson lower bound (5d horizon).
Wilson 95% CI — binomial proportion confidence interval; renders as 0.62 [0.51–0.79]. Low-CI floor is what we trust, not point estimate.
5d return — close-to-close return at 5 trading days from activation, net of 10 bps round-trip. Conditional on activation per ADR-0003.
