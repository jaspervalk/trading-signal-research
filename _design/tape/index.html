[ DESIGN NOTES · JUNIOR PASS · 2026-05-05 ]
· assumption_1: ticker page is one route; live-signal strip is read-only and recomputed by tsr aggregate-signals nightly — UI never writes.
· assumption_2: chart is approximation only — true candles render via lightweight-charts in production; SVG silhouette here is mock-fidelity.
· assumption_3: every metric carries N + Wilson 95% CI as a peer; bracketed mono `0.62 [0.41–0.79]` is the locked house format (per ADR-0005).
· decision: oxblood #B83227 over signal-orange — oxblood reads as a research/print accent (FT Alphaville, lab-notebook stamps), orange would have leaned dashboard-tech and undermined the data-zine register. Used sparingly: timestamps in tape headers, negative polarity, key links, banner border.
· decision: mono-only (IBM Plex Mono) — type IS the data. Mixing serif/sans would invite a magazine read; we want a reader who feels they're handling raw receipts. Tracking is wide on labels (0.10em+) for caps legibility, tight on the ticker (-0.04em) for poster weight.
· decision: warning banner shown in demo/inactive mode w/ caption `[N=15 · ABOVE THRESHOLD · BANNER SUPPRESSED IN PRODUCTION]` — makes the warning grammar visible as a design feature even when production would suppress it. "We walk the talk" needs to be visible without lowering data quality.
· tradeoff: ASCII polarity bars are a strong identity move but accessibility is unresolved — production will need aria-label like "net polarity +0.50, n=4 mentions" on each bar; sighted-only design is not sufficient.
· tradeoff: oversized 112px ticker is poster-grade on desktop, but on <640px viewports it must clamp to ~64px before it line-breaks — not yet handled in this static mock.
· tradeoff: header "historical only" badge slot is reserved but empty (most-recent mention 2026-04-30 = 5d ago); decided not to render a placeholder so header weight stays correct in the live state.
· inspiration: Are.na index pages × FT Alphaville's print-DNA × Read.cv's bracketed metadata × Dia Browser's lab-notebook footer voice. North star: a Bloomberg terminal's data density + a printed errata sheet's epistemic posture.

mean of {−1, 0, +1} polarities across all claims in window. range [−1, +1].
weighted
credibility-weighted polarity using creator hit_rate_lower_ci (wilson-95 lci on prior calls) as weight.
claims_factual
